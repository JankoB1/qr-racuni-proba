# QR Računi, web proba

Probna web verzija skenera fiskalnih računa (suf.purs.gov.rs), za poređenje sa mobilnom aplikacijom na telefonima. Ovde su samo gotovi fajlovi stranice: ZXing i obrada slike rade u browseru kao WebAssembly, ništa se ne šalje na server.

Stranica: https://jankob1.github.io/qr-racuni-proba/
